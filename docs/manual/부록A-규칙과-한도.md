# 부록 A — 규칙과 한도

사이트 전체에 걸쳐 적용되는 숫자와 규칙을 한곳에 모았습니다. "이거 몇 MB까지 되지?", "이 데이터 언제 지워지지?" 같은 질문의 답이 여기 있습니다.

이 문서의 값은 전부 코드에서 확인한 것입니다. 코드를 고치면 이 문서도 같이 고쳐야 합니다.

---

## A-1. 파일 업로드

### 공지 첨부파일

| 항목 | 값 |
|---|---|
| 최대 크기 | **파일당 30MB** |
| 최대 개수 | **공지당 10개** (11개째부터 서버가 잘라 냄) |
| 허용 확장자 | pdf, hwp, hwpx, doc, docx, xls, xlsx, ppt, pptx, zip, txt, csv, png, jpg, jpeg, gif, webp — **17종** |
| 저장 위치 | 학생회 구글 드라이브의 「공지 첨부」 폴더 |
| 드라이브 미연결 시 | 사이트 저장소로 대체 저장. 이때는 **4MB 이하만** 가능 |

**확장자만 바꾼 파일은 거부됩니다.** 업로드가 끝난 뒤 서버가 파일 앞부분을 읽어 실제 형식이 확장자와 맞는지 확인하고, 다르면 드라이브에서 지운 뒤 오류를 냅니다. 예를 들어 실행파일 이름을 `보고서.pdf` 로 바꿔 올려도 통과하지 못합니다.

**학생은 드라이브를 보지 않습니다.** 첨부는 우리 사이트 주소로 내려받습니다. 드라이브 파일을 공개로 바꾸지 않으며, 드라이브 링크도 노출되지 않습니다.

### 이미지 (공지 본문, 상품 사진, 구성원 사진 등)

| 항목 | 값 |
|---|---|
| 최대 크기 | **4MB** |
| 허용 형식 | JPG, PNG, WebP, GIF |
| 저장 위치 | 사이트 저장소 |
| 자동 처리 | **촬영 정보(EXIF) 제거** — 사진에 박힌 촬영 위치·기기 정보가 지워집니다 |

> 4MB는 임의로 정한 값이 아닙니다. 서버가 한 번에 받을 수 있는 요청 크기가 4.5MB로 묶여 있어서, 그 안쪽으로 잡은 값입니다. 첨부파일이 30MB까지 되는 것은 파일을 3MB씩 잘라 보내기 때문입니다.

### 학습자료

| 항목 | 값 |
|---|---|
| 최대 크기 | **100MB** |
| 저장 위치 | 구글 드라이브 「학습자료」 폴더 아래 과목코드별 폴더 |
| 공개 방식 | 드라이브 공유 링크 |

학습자료와 평면도 업로드는 공지 첨부와 달리 파일 형식을 앞부분까지 검사하지는 않습니다. 관리자만 올릴 수 있는 화면이라 위험이 낮지만, 출처가 불확실한 파일은 올리지 마세요.

## A-2. 개인정보 — 무엇을 저장하고 무엇을 저장하지 않나

### 저장하지 않는 것

| 항목 | 어떻게 |
|---|---|
| **학번 원문** | 대조용 해시만 저장. 관리자 화면에도 학번은 보이지 않습니다 |
| **과비 확인에 입력한 학번** | 아예 저장하지 않습니다. 주소창에도 남지 않습니다 |
| **IP 주소 원문** | 해시만 저장 |
| **주문 관리 코드 원문** | 해시만 저장. 그래서 잃어버리면 다시 알려 드릴 수 없습니다 |
| **후기 비밀번호** | 되돌릴 수 없는 형태로만 저장 |

### 저장하는 것

- 캠페인 신청: 이름, 이메일, 전화번호, 입금자명, 학번 해시, 주문 항목·금액·상태
- 건의함: 답변받을 연락처(적었을 때만)
- 익명 게시판: 글 내용, 익명 태그, IP 해시
- 알림 구독: 브라우저가 발급한 구독 주소와 기기 종류

전화번호는 **관리자 화면과 CSV에서만** 보입니다. 공개 화면에는 나가지 않습니다.

### 자동으로 지워지는 것 (매주 일요일 정리)

| 데이터 | 기간 | 무엇이 지워지나 |
|---|---|---|
| 건의함 연락처 | 답변 후 **30일** | 연락처만 |
| 조회수 중복 판정 기록 | **90일** | 누구가 봤는지의 기록. 누적 조회수는 남음 |
| IP 해시 (글·댓글·건의·강의평) | **90일** | 해시만 |
| 신고 기록 | **180일** | 전체 |
| 관리자 작업 기록 | **180일** | 전체 |
| 알림 구독 | 연속 실패 5회 또는 **180일** 무응답 | 전체 |
| 캠페인 신청 | 마감 후 **180일** | 이름·이메일·전화·학번해시·입금자명·메모. **항목·금액·상태는 통계용으로 남습니다** |

같은 작업이 전체 데이터를 암호화해 백업합니다.

> ⚠️ **개인정보처리방침과 어긋나는 부분이 있습니다.** 방침 본문에는 "쿠키는 관리자 로그인 세션 쿠키만 사용" 이라고 적혀 있지만, 실제로는 조회수·좋아요 중복을 막기 위해 모든 방문자에게 1년짜리 방문자 쿠키가 발급됩니다. 조회수·좋아요 수집과 알림 구독 정보도 방침에 적혀 있지 않습니다. 방침 문구를 고쳐야 합니다.

## A-3. 접속 제한

### 관리자 로그인

| 항목 | 값 |
|---|---|
| 계정 기준 | 10분 동안 **10회** 실패하면 잠김 |
| IP 기준 | 10분 동안 **20회** 실패하면 잠김 |
| 잠긴 동안 | 올바른 비밀번호를 넣어도 로그인되지 않습니다 |
| 풀리는 시점 | 마지막 실패로부터 10분 |

잠긴 상태와 비밀번호가 틀린 상태는 **같은 문구**로 보입니다. 계정이 있는지 없는지를 공격자에게 알려 주지 않기 위해서입니다. 비밀번호가 맞는데 계속 안 되면 10분 기다렸다가 다시 해 보세요.

### 학생용 화면 (IP 기준, 1분당)

| 기능 | 한도 |
|---|---|
| 건의사항 등록 | 2회 |
| 게시글 작성 | 3회 |
| 강의평 작성 | 5회 |
| 신고 | 5회 |
| 댓글 | 10회 |
| 알림 구독·해지 | 20회 |
| 좋아요, 공지 첨부 다운로드 | 30회 |
| 캠페인 신청·조회·취소, 조회수 집계 | 60회 |

한도를 넘으면 "요청이 너무 많습니다. 잠시 후 다시 시도해주세요." 가 나옵니다. 1분 뒤면 풀립니다.

## A-4. 알림(웹 푸시)

### 받을 수 있는 조건

1. **https 로 접속** — 사이트는 항상 https 이므로 자동 충족
2. **브라우저가 지원** — 크롬·엣지·파이어폭스·사파리 16.4 이상
3. **아이폰·아이패드는 홈 화면에 추가한 뒤 그 아이콘으로 열어야 함** — 애플이 사파리 탭에서는 알림 기능 자체를 제공하지 않습니다. 우회할 방법이 없습니다.
4. **알림 권한 허용**

사이트는 아이폰에서 위 조건이 안 맞으면 켜기 버튼 대신 설치 안내를 보여 줍니다.

### 언제 발송되나

알림은 **관리자가 명시적으로 보낼 때만** 나갑니다. 자동 발송은 없습니다.

| 경로 | 대상 |
|---|---|
| 공지 작성 시 "알림 보내기" 체크 | 구독자 전원 |
| 공지 목록의 "알림" 버튼 | 구독자 전원 |
| "알림 시험 발송 (내 기기)" 버튼 | **누른 기기 하나만** |

### 발송 결과 문구의 뜻

| 화면에 나오는 말 | 실제 상태 | 조치 |
|---|---|---|
| 알림을 n명에게 보냈습니다 | 전부 성공 | 없음 |
| n명에게 보냈고 m건 실패 | 일부 기기가 만료·응답 없음 | 만료된 구독은 자동 정리됨. 조치 불필요 |
| 알림을 받도록 설정한 사람이 아직 없습니다 | 구독자 0명 | 공지로 "알림 받기" 안내 |
| 이 기기의 알림 구독을 찾지 못했습니다 | 시험 발송인데 이 기기가 알림을 안 켬 | 공지 페이지에서 알림 받기를 먼저 켜기 |
| 구독자 목록을 불러오지 못했습니다 | 데이터베이스 일시 장애 | 잠시 후 재시도 |
| 알림 발송 설정이 되어 있지 않습니다 | 서버 설정(VAPID 키) 누락 | 개발자 문의 |

**저장과 알림은 별개입니다.** 알림이 실패해도 공지는 저장돼 있습니다. 다시 등록하지 말고 목록의 "알림" 버튼으로 재발송하세요.

### 구독이 자동으로 지워지는 경우

- 브라우저가 "이 구독은 없어졌다"고 응답할 때 (앱 삭제, 브라우저 데이터 삭제 등) — 즉시 삭제
- 연속 5회 발송 실패 — 삭제
- 180일 동안 한 번도 성공하지 못함 — 삭제

학생이 다시 켜면 새로 등록됩니다.

## A-5. 화면에 바로 반영되지 않는 것들

관리자가 고쳤는데 공개 화면에 바로 안 보이는 경우가 있습니다. 성능을 위해 일정 시간 화면을 저장해 두기 때문입니다.

| 화면 | 최대 지연 |
|---|---|
| 홈 | 즉시 (공지 저장 시 자동 갱신) |
| 공지 목록·상세 | 즉시 |
| 학부 소개(구성원·동아리·마스코트) | **최대 5분** |
| 학과 안내(교수·건물·평면도) | **최대 5분** |
| 전공서적 | 최대 1분 |
| 수업 정보 | 최대 1분 |
| 자유게시판 글 | 즉시 |

**5분 지연되는 화면을 고친 뒤 "안 바뀌었다"고 다시 저장하지 마세요.** 중복이 생깁니다. 5분 기다렸다가 확인하세요.

## A-6. 캠페인 주문의 상태

### 상태 네 가지

| 상태 | 화면 표기 | 뜻 |
|---|---|---|
| pending | 대기 | 신청은 됐고 입금 확인 전 |
| paid | 입금 확인 | 입금이 확인됨 |
| delivered | 수령 완료 | 물건을 건넸음 |
| cancelled | 취소 | 취소됨. 재고가 자동으로 돌아옴 |

### 누가 상태를 바꿀 수 있나

| 전이 | 누가 | 조건 |
|---|---|---|
| (없음) → 대기 | 학생 | 캠페인이 공개돼 있고 신청 기간 안일 때 |
| 대기 → 취소 | **학생 본인** | 주문번호 + 관리 코드 필요. **입금 확인 전에만** |
| 무엇이든 → 무엇이든 | 관리자 | 제한 없음. 입금 취소(입금 확인 → 대기)도 가능 |

**CSV로 적재한 주문은 학생이 스스로 취소할 수 없습니다.** 관리 코드가 없기 때문입니다. 학생회가 대신 처리해야 합니다.

### 관리 코드

- 신청이 끝나는 순간 화면에 **한 번만** 표시됩니다.
- 8자리, 헷갈리는 글자(0, O, 1, I)는 빼고 만듭니다.
- 서버에는 되돌릴 수 없는 형태로만 저장돼 있어서, **잃어버리면 다시 알려 드릴 수 없습니다.** 본인 확인 후 학생회가 대신 취소해야 합니다.

### 재고

재고는 따로 세어 두는 숫자가 아니라 **매번 계산**합니다.

```
남은 수량 = 설정한 재고 − (취소되지 않은 주문들의 그 옵션 수량 합)
```

그래서 신청하는 즉시 줄어들고, 취소하면 즉시 돌아옵니다. 재고를 손으로 맞출 필요가 없습니다.

동시에 여러 명이 마지막 하나를 신청해도 한 명만 성공합니다. 나머지에게는 "남은 수량이 부족합니다" 가 나갑니다.

### 1인 최대 수량

- **한 주문이 아니라 그 사람의 모든 주문을 합산**합니다. 3개 제한인데 2개 신청한 사람은 2개를 더 신청할 수 없습니다.
- 취소한 주문은 합산에서 빠집니다.
- 같은 사람인지는 학번 해시로 판단하고, 학번이 없으면 이메일+이름으로 판단합니다.

### 중복 신청

같은 사람이 여러 번 신청하는 것 자체는 막지 않습니다(1인 최대 수량에만 걸립니다). 다만 **버튼을 두 번 눌러서 생기는 중복 주문은 자동으로 막습니다** — 같은 요청은 기존 주문을 그대로 돌려줍니다.

## A-7. 서버 설정값 (개발자용)

사이트를 다른 곳에 새로 띄우려면 아래 환경변수가 필요합니다. **값은 절대 문서나 채팅에 적지 마세요.**

| 이름 | 용도 |
|---|---|
| `DATABASE_URL`, `TURSO_AUTH_TOKEN` | 데이터베이스 연결 |
| `ANON_SALT` | 학번·IP·관리코드 해시의 소금값. **프로덕션에서 없으면 사이트가 아예 뜨지 않습니다** |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | 관리자 계정 |
| `CRON_SECRET` | 주간 정리·백업 작업 인증 및 백업 암호화 |
| `NEXT_PUBLIC_SITE_URL` | 사이트 주소 (사이트맵·공유 카드) |
| `NEXT_PUBLIC_ICAL_URL` | 학사일정 구독 주소 |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | 웹 푸시 알림 |
| `GOOGLE_FEE_CSV_URL`, `FEE_STUDENT_ID_COLUMN` | 과비 확인 시트 |
| `GOOGLE_DRIVE_API_KEY` | 드라이브 조회 |
| `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`, `GOOGLE_OAUTH_REDIRECT_URI` | 드라이브 쓰기 연동 |

> `ANON_SALT` 를 바꾸면 **기존 학번 해시가 전부 무효**가 됩니다. 예전 주문을 학번으로 조회할 수 없게 되니 절대 바꾸지 마세요.
