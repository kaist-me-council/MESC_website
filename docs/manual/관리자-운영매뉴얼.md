# 기계과 학생회 사이트 운영 매뉴얼 (관리자용)

관리자 주소: **https://mesc-website.vercel.app/admin**
공용 컴퓨터에서 썼다면 오른쪽 위 **로그아웃** 을 꼭 누르세요.

---

## 1. 대시보드 — 오늘 할 일부터 본다

![관리자 대시보드](images/11-admin-dashboard.jpg)

로그인하면 맨 위에 **오늘 처리할 일** 네 가지가 숫자로 나옵니다.

| 카드 | 뜻 | 누르면 |
|---|---|---|
| 입금 대기 | 신청했는데 아직 입금 확인 안 한 건 | 이벤트 신청·구매 |
| 수령 확인 미응답 | 받았는지 아직 답 안 한 사람 | 이벤트 신청·구매 |
| 미답변 건의 | 답변 안 단 건의 | 커뮤니티·건의 |
| 미처리 신고 | 신고가 들어온 글 | 커뮤니티·건의 |

숫자 대신 `-` 가 보이면 집계를 못 불러온 것입니다. 0건이라는 뜻이 아니니 새로고침해 주세요.

왼쪽 메뉴는 네 묶음입니다. **신청·사업 운영**(기간이 정해진 일), **소식·소통**(공지·사진·건의·팝업), **학과·학습 정보**(가끔 손보는 기준 데이터), **학생회·사이트 설정**.

각 화면 위에는 그 화면의 사용법이 접혀 있습니다. 한 번 읽고 접어 두면 다음에도 접힌 채로 열립니다.

## 2. 공지사항

![공지 관리 사용법](images/12-admin-notices-guide.jpg)

### 공지 쓰기

1. 제목과 내용을 넣고 카테고리(공지·행사·학사)를 고릅니다.
2. **EN 자동 채우기** 를 누르면 영문 칸에 초안이 들어갑니다. **반드시 읽어 보고 고친 뒤** 등록하세요.
3. **상단 고정** 을 켜면 공개 페이지 맨 위에 붙습니다.
4. **알림 보내기** 를 켜면 등록과 동시에 구독자에게 푸시가 갑니다.

> 알림은 **꼭 필요한 공지에만** 켜세요. 모든 공지에 보내면 학생들이 알림을 꺼 버립니다.

### 첨부파일

- 최대 10개, 각 30MB. PDF·한글·오피스·이미지·ZIP.
- 파일은 **학생회 구글 드라이브의 「공지 첨부」 폴더** 에 저장됩니다. 학생은 드라이브를 거치지 않고 우리 사이트에서 바로 내려받습니다. 드라이브에서 파일을 공개로 바꿀 필요가 없습니다.
- 올리는 동안 진행률이 퍼센트로 보입니다.
- 공지를 지우면 드라이브 파일도 함께 지워집니다.
- 확장자만 바꾼 파일(예: 실행파일을 .pdf 로)은 자동으로 거부됩니다.

### 이미 올린 공지에 알림 보내기

![공지 목록](images/13-admin-notice-list.jpg)

목록의 각 줄에 **알림 / 수정 / 삭제** 버튼이 있습니다.

- **알림** — 그 공지를 구독자에게 (다시) 보냅니다.
- 목록 위 **알림 시험 발송** — 공지를 만들지 않고 내 기기로만 시험해 봅니다.

발송하면 결과가 문장으로 나옵니다.

| 결과 | 뜻 |
|---|---|
| 알림을 n명에게 보냈습니다 | 정상 |
| n명에게 보냈고 m건 실패 | 일부 기기가 만료됨. 만료된 구독은 자동 정리됨 |
| 받도록 설정한 사람이 아직 없습니다 | 아무도 알림을 켜지 않음 |
| 발송 설정이 되어 있지 않습니다 | 서버 설정 문제. 개발자에게 문의 |

**저장과 알림은 별개입니다.** 알림이 실패해도 공지는 저장된 상태이니 다시 등록하지 마세요. 목록의 **알림** 버튼으로 다시 보내면 됩니다.

## 3. 학생회 이벤트 (단체복·행사 신청)

![이벤트 관리](images/14-admin-campaigns.jpg)

구글폼 대신 쓰는 화면입니다. 신청받고, 입금 확인하고, 배부까지 여기서 합니다.

### 캠페인 만들기

- **새 캠페인**: 제목과 주소(영문·숫자·하이픈)를 넣으면 설정 화면으로 갑니다. 공개 주소는 `/apply/주소` 입니다.
- **상반기 반팔티(수령 확인용) 만들기**: 이미 배부가 끝난 반팔티용으로, 흰/검 × 7사이즈 옵션과 수령 확인이 켜진 캠페인을 한 번에 만듭니다.

### 설정 탭에서 정하는 것

| 항목 | 설명 |
|---|---|
| 종류 | **굿즈** 면 색상·사이즈 칩이 있는 상품 화면, **일반 신청** 이면 목록 화면 |
| 이미지 | 최대 8장. 첫 장이 대표. 시안과 사이즈표를 함께 올리면 좋습니다 |
| 공개 | 꺼 두면 학생에게 안 보이고 **관리자만 미리보기** 할 수 있습니다 |
| 기간 | 시작·마감. 비우면 즉시·무기한 |
| 옵션 | 그룹(색상) + 이름(사이즈) + 가격 + 재고. **옵션 일괄 추가** 로 한 줄에 하나씩 붙여넣기 가능 |
| 구분별 가산 | 대학원생·교수님 등에 얹을 금액 |
| 1인 최대 수량 | 같은 사람의 여러 주문을 합산해 제한합니다 |
| 계좌·완료 안내 | 신청 완료 화면에만 보입니다 |
| 수령 확인 | 켜면 `/apply/주소/confirm` 이 열립니다 |

> **공개하기 전에 미리보기로 확인하세요.** 관리자로 로그인한 상태에서 공개 주소를 열면 실제 학생 화면을 그대로 볼 수 있고, 위에 "비공개 미리보기" 배너가 뜹니다.

### 신청 목록 탭

- 맨 위 **정산 카드**: 입금 확인 금액, 입금 대기 금액, 수령 완료 벌 수, 환불 대기 건수와 금액.
- **체크박스로 여러 건을 골라** 입금 확인 / 입금 취소 / 수령 완료 / 취소를 한 번에 처리합니다.
- **수령 완료** 를 누르면 **배부 담당자 이름** 을 묻습니다. 누가 건넸는지 기록으로 남습니다.
- **환불 필요** 표시가 붙은 건은 처리 후 **환불 완료** 를 눌러 두세요.
- **옵션별 합계** 가 그대로 발주표입니다.
- **이메일 복사** 로 현재 필터의 이메일을 한 번에 복사해 Gmail 받는 사람에 붙여넣습니다. 미응답만 걸러 독촉 메일을 보낼 때 씁니다.
- **CSV 내보내기** 로 정산 명단을 뽑습니다.
- 전화·문자로 받은 답은 **수령 확인 탭** 에서 대신 기록할 수 있습니다.

### 데이터 가져오기 탭

이미 끝난 구매(구글폼·엑셀)를 주문으로 넣습니다.

1. 시트를 CSV 로 내려받습니다.
2. 모드를 고릅니다. 배부 시트 형식이면 **배부 시트**, 아니면 **일반 CSV**.
3. **미리보기** 로 몇 건이 해석되는지, 문제 행이 없는지 봅니다.
4. 문제가 없을 때만 **적재** 버튼이 켜집니다.

> **"기존 적재분 교체" 는 기본으로 꺼져 있습니다.** 켜면 이전에 적재한 주문이 지워집니다. 미리보기에서 몇 건이 지워지는지, 그중 수령 확인 응답이 몇 건인지 보여 주니 꼭 읽고 실행하세요. 학생이 직접 신청한 건은 지워지지 않습니다.

## 4. 마스코트와 사이트 설정

**사이트 설정** 화면에 탭이 네 개 있습니다.

- **운영시간·연락처** — 푸터와 홈에 나오는 정보
- **링크** — 주요 링크와 SNS
- **동아리** — 학부 소개의 과동아리
- **마스코트** — 학부 소개의 마스코트 탭

마스코트는 사진(투명 배경 PNG 권장)과 이름, 한 줄 소개, 본문을 넣고 **공개** 를 켜면 학생에게 보입니다. 준비가 안 됐으면 공개를 꺼 두세요. 등록된 마스코트가 하나도 없으면 탭 자체가 나타나지 않습니다.

## 5. 개인정보 취급

- **학번은 원문을 저장하지 않습니다.** 대조용 해시만 남아서 관리자 화면에도 학번이 보이지 않습니다.
- 연락처는 관리자만 봅니다. 공개 화면에는 나가지 않습니다.
- 캠페인 마감 180일 뒤 이름·이메일·전화·메모가 **자동으로 익명화** 됩니다. 항목·금액·상태는 통계용으로 남습니다.
- 건의함 연락처는 답변 후 30일 안에 지워집니다.
- 관리자가 주문 상태를 바꾸거나 무언가를 지우면 **누가 했는지 기록** 이 남습니다. 개인정보 원문은 기록하지 않습니다.

## 6. 곤란할 때

| 증상 | 확인할 것 |
|---|---|
| 첨부가 "사이트 저장소" 로 저장됨 | 드라이브 연결이 끊긴 상태입니다. 사이트 설정에서 다시 연결하세요 |
| 알림을 보냈는데 "받도록 설정한 사람이 없습니다" | 아직 아무도 알림을 켜지 않았습니다. 공지로 안내해 주세요 |
| 저장에 실패했다고 뜸 | 쓰던 내용과 첨부는 그대로 있습니다. 문구를 확인하고 다시 저장하세요 |
| "저장 완료, 목록 갱신 실패" | 공지는 저장됐습니다. 새로고침만 하세요. 다시 등록하면 중복됩니다 |
| 로그인이 안 됨 | 비밀번호를 여러 번 틀리면 10분간 잠깁니다. 잠시 뒤 다시 시도하세요 |
| 학생이 첨부를 못 받는다고 함 | 공지를 지웠거나 첨부를 교체하지 않았는지 확인하세요 |
