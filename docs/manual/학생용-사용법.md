# 기계과 학생회 사이트 사용법 (학생용)

주소: **https://mesc-website.vercel.app**
로그인이 필요 없습니다. 휴대폰으로 열어도 그대로 쓸 수 있습니다.

---

## 1. 무엇을 할 수 있나요

![홈 화면](images/01-home.jpg)

한 곳에서 이런 것들을 할 수 있습니다.

- 학생회 **공지사항** 보기, 새 공지 **알림** 받기
- 단체복·행사 **신청과 결제 안내** 확인
- **과비 납부** 여부 조회
- 학과 **일정**, **학습자료**, **전공서적**, **강의 정보** 찾기
- **건의함**과 익명 게시판에 의견 남기기

화면 오른쪽 위에서 **English** 로 바꿀 수 있고, 해 모양 버튼으로 어두운 화면으로 바꿀 수 있습니다.

---

## 2. 공지사항 보기

![공지사항 목록](images/02-notices.jpg)

- 위쪽 탭으로 **공지 / 행사 / 학사** 를 나눠 볼 수 있습니다.
- 📌 표시가 붙은 공지는 항상 맨 위에 있습니다.
- 제목을 누르면 전체 내용을 볼 수 있습니다.

![공지 상세](images/03-notice-detail.jpg)

**첨부파일이 있으면** 본문 아래에 파일 이름이 보입니다. 누르면 바로 내려받아집니다. 다른 사이트로 넘어가지 않습니다.

---

## 3. 새 공지 알림 받기 ⭐

공지가 올라오면 휴대폰으로 알림을 받을 수 있습니다.

### 아이폰

아이폰은 **홈 화면에 추가한 다음에만** 알림을 받을 수 있습니다. 사파리 탭으로 열어 둔 상태에서는 안 됩니다. 애플 정책이라 어쩔 수 없습니다.

1. 사파리로 사이트를 엽니다.
2. 아래쪽 **공유 버튼**(↑ 네모)을 누릅니다.
3. **홈 화면에 추가** 를 누릅니다.
4. 홈 화면에 생긴 **아이콘으로** 다시 엽니다.
5. 공지사항 페이지에서 **알림 받기** 를 누르고 허용합니다.

### 안드로이드·컴퓨터

공지사항 페이지 오른쪽 위 **알림 받기** 를 누르고 허용하면 끝입니다. 화면 위에 "홈 화면에 추가하면 앱처럼 쓸 수 있어요" 안내가 뜨면 **추가** 를 눌러 앱처럼 쓸 수도 있습니다.

> 알림을 끄고 싶으면 같은 버튼을 다시 누르면 됩니다.

---

## 4. 단체복·행사 신청 (학생회 이벤트)

![학생회 이벤트](images/04-apply-list.jpg)

메뉴에서 **학과 도우미 → 학생회 이벤트** 로 들어갑니다.

### 신청하는 법

1. 신청할 이벤트를 고릅니다.
2. 단체복이라면 **색상 → 사이즈 → 수량** 을 고르고 담습니다. 품절인 사이즈는 회색으로 표시됩니다.
3. 이름, 구분(학부생·대학원생 등), 학번, 연락처를 적습니다.
4. 금액을 확인하고 **신청** 을 누릅니다.

### 신청이 끝나면 꼭 확인하세요

완료 화면에 **주문번호**, **금액**, **입금 계좌**, 그리고 **관리 코드** 가 나옵니다.

> **관리 코드는 이때 한 번만 보여 줍니다.** 나중에 신청을 취소하려면 이 코드가 필요하니 화면을 캡처하거나 적어 두세요. 잃어버리면 학생회에 문의해야 합니다.

입금할 때 **입금자명은 신청서에 적은 이름과 같게** 해 주세요. 다르면 신청서의 "입금자명" 칸에 적어 주시면 됩니다.

### 내 신청 확인하기

같은 페이지 아래 **내 신청 확인** 에서 볼 수 있습니다. 세 가지 방법 중 편한 것을 쓰세요.

- 이름 + 학번
- 이름 + 이메일
- 주문번호

상태가 **대기 → 입금 확인 → 수령 완료** 로 바뀝니다. 입금 확인 전이라면 **주문번호와 관리 코드**로 직접 취소할 수 있습니다. 입금이 확인된 뒤에는 학생회에 문의해 주세요.

---

## 5. 옷 받았는지 확인하기 (수령 확인)

![수령 확인](images/05-confirm.jpg)

단체복처럼 이미 배부가 끝난 건은 **받았는지 알려 주는 화면**이 따로 열립니다.

1. 이름과 학번(또는 이메일, 주문번호)으로 조회합니다.
2. 주문 내역을 확인합니다.
3. **받았어요** 또는 **못 받았어요** 를 누릅니다.
4. 못 받았다면 항목마다 **학생회실에서 수령 / 환불 / 다른 사이즈로 교환** 중에서 고릅니다.

환불 계좌는 이 화면에서 받지 않습니다. 학생회에서 개별로 연락드립니다.

---

## 6. 과비 납부 확인

![과비 확인](images/06-check-fee.jpg)

**일정·재정 → 과비 확인** 에서 학번만 넣으면 납부 횟수가 바로 나옵니다.

입력한 학번은 조회에만 쓰이고 **서버에 저장되지 않습니다.** 주소창에도 남지 않습니다.

---

## 7. 학부 소개와 마스코트

![마스코트](images/07-mascot.jpg)

**학과 도우미 → 학부 소개** 에서 학생회 구성원, 과동아리, 그리고 **마스코트** 를 볼 수 있습니다.

---

## 8. 그 밖에

| 하고 싶은 것 | 어디로 |
|---|---|
| 학과 일정 보기, 내 캘린더에 넣기 | 일정·재정 → 캘린더 |
| 강의자료·족보 찾기 | 강의 관련 → 학습자료 |
| 과목 정보와 강의평 보기 | 강의 관련 → 수업 정보 |
| 학생회 보유 전공서적 찾기 | 강의 관련 → 전공서적 |
| 교수님 연구실 위치 찾기 | 학과 도우미 → 학과 안내 |
| 학생회에 하고 싶은 말 | 커뮤니티 → 건의함 |
| 익명으로 이야기 나누기 | 커뮤니티 → 자유게시판 |
| 먹고 싶은 간식 신청 | 커뮤니티 → 간식 위시리스트 |

건의함과 자유게시판은 **이름을 적지 않아도 됩니다.** 답변을 받고 싶을 때만 연락처를 남기면 되고, 답변이 끝나면 지웁니다.

---

## 9. 자주 묻는 것

**로그인해야 하나요?**
아니요. 학생이 쓰는 기능은 전부 로그인 없이 됩니다.

**알림을 켰는데 안 와요.**
아이폰이라면 홈 화면에 추가한 앱에서 켰는지 확인해 주세요. 사파리 탭에서 켠 것은 동작하지 않습니다.

**관리 코드를 잃어버렸어요.**
학생회에 문의해 주세요. 본인 확인 후 처리해 드립니다.

**신청 내역이 조회가 안 돼요.**
신청할 때 적은 이름과 정확히 같아야 합니다. 띄어쓰기는 무시되지만 글자가 다르면 찾지 못합니다. 주문번호로 조회해 보세요.
