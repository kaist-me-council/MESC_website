# 기계공학과 학생회 사이트 매뉴얼

사이트: **https://mesc-website.vercel.app**

| 문서 | 누구를 위한 것 |
|---|---|
| **[학생용 사용법](학생용-사용법.md)** | 학생 전체. 공지 알림, 이벤트 신청, 과비 확인 등 |
| **[관리자 운영 매뉴얼](관리자-운영매뉴얼.md)** | 학생회 임원. 인수인계 때 이 문서를 넘기세요 |
| **[부록 A — 규칙과 한도](부록A-규칙과-한도.md)** | 정확한 숫자가 필요할 때 (파일 크기, 보유 기간, 상태 규칙) |
| **[부록 B — 오류 문구 사전](부록B-오류-문구-사전.md)** | 화면에 뜬 문구로 원인 찾기 |
| **[카드뉴스](cardnews/)** | 인스타그램 1:1 8장. 신입생 안내용 |

## 상황별로 어디를 볼까

| 상황 | 문서 |
|---|---|
| 신입생에게 사이트를 소개해야 한다 | 카드뉴스 → 학생용 사용법 |
| 학생이 "이거 안 돼요"라고 문의했다 | 부록 B에서 문구 검색 |
| 단체복 판매를 처음 열어 본다 | 관리자 매뉴얼 2장 |
| 공지에 파일을 첨부하려는데 안 된다 | 관리자 매뉴얼 3-2 → 부록 B |
| 무언가를 지워도 되는지 모르겠다 | **관리자 매뉴얼 9장 (되돌릴 수 없는 작업)** |
| 집행부가 바뀐다 | 관리자 매뉴얼 12장 (인수인계 체크리스트) |
| 개인정보를 어디까지 다뤄도 되나 | 관리자 매뉴얼 10장, 부록 A-2 |

## 문서를 고칠 때

- 화면 캡처는 `images/` 에 있습니다. 화면이 바뀌면 다시 찍어 같은 파일명으로 덮어쓰세요.
- 카드뉴스 이미지는 직접 편집하지 말고 `scripts/make-cardnews.mjs` 의 문구를 고친 뒤 다시 만드세요. 자세한 것은 [cardnews/README.md](cardnews/README.md).
- 부록 A의 숫자는 전부 코드에서 확인한 값입니다. **코드를 고치면 부록 A도 같이 고쳐야 합니다.**
