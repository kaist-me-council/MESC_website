## 내용 고치기

이미지를 직접 편집하지 말고 `scripts/make-cardnews.mjs` 아래쪽 `cards` 배열의 문구를 고친 뒤 다시 만드세요.

```
node scripts/make-cardnews.mjs
```

**매뉴얼을 고쳤으면 카드도 같이 맞춰 주세요.** 내용은 학생용 사용법을 따릅니다.

### 두 가지 제약

- **자동 줄바꿈이 없습니다.** 배열에서 한 줄씩 직접 나눠야 하고, 본문은 한 줄에 22자 안쪽이 적당합니다.
- **이모지는 렌더되지 않습니다.** 문구에 넣지 마세요.

목록·강조 띠·하단 문구는 위치를 자동으로 계산하므로, 항목 수를 늘리거나 줄여도 겹치지 않습니다.
