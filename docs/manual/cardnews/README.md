# 카드뉴스 (인스타그램 1:1)

`card-01.png` … `card-08.png` — 1080×1080. 학생용 사용법(`../학생용-사용법.md`)을 8장으로 요약한 것입니다.
번호 순서대로 캐러셀에 올리면 됩니다.

## 내용 고치기

이미지를 직접 편집하지 말고 `scripts/make-cardnews.mjs` 아래쪽 `cards` 배열의 문구를 고친 뒤 다시 만드세요.

```
node scripts/make-cardnews.mjs
```

줄바꿈은 자동으로 되지 않습니다. 배열에서 한 줄씩 직접 나눠야 하고, 본문은 한 줄에 20자 안쪽이 적당합니다.
