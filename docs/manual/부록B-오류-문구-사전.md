# 부록 B — 오류 문구 사전

화면에 나오는 안내 문구를 그대로 찾아, 무슨 뜻이고 무엇을 하면 되는지 적었습니다. 학생이 문의해 왔을 때 이 표에서 문구를 찾으면 답이 나옵니다.

**찾는 법**: 브라우저에서 `Ctrl+F`(맥은 `⌘+F`)로 문구 일부를 검색하세요.

---

## B-1. 학생이 보는 문구

### 신청·구매

| 문구 | 실제 원인 | 학생에게 할 답 |
|---|---|---|
| 요청이 너무 많습니다. 잠시 후 다시 시도해주세요. | 1분에 60번 넘게 요청함. 보통은 새로고침 연타 | 1분 뒤 다시 해 보라고 안내 |
| 신청 기간이 아닙니다. | 시작 전이거나 마감됨 | 기간 확인. 연장하려면 관리자 설정에서 마감일 변경 |
| 선택할 수 없는 옵션입니다. | 관리자가 그 옵션을 지웠거나 껐음. 학생 화면이 옛 상태 | 새로고침 후 다시 선택 |
| 수량이 올바르지 않습니다. | 1~99 범위 밖 | 수량 확인 |
| 1인당 최대 N개까지 신청할 수 있습니다. | 이번 신청만으로 한도 초과 | 수량 줄이기 |
| 1인당 최대 N개까지 신청할 수 있습니다. (이미 M개 신청) | **이전 신청과 합쳐서** 한도 초과 | 이전 신청을 취소하거나 수량 줄이기 |
| '옵션명' 남은 수량이 부족합니다. (남음 N) | 그 사이 다른 사람이 먼저 가져감 | 남은 수량 안에서 다시 신청 |
| 동시에 신청이 몰렸습니다. 잠시 후 다시 시도해주세요. | 같은 순간에 여러 신청이 겹침 | 그대로 다시 시도. 중복 주문은 생기지 않음 |
| 주문번호 또는 관리 코드가 올바르지 않습니다. | 주문번호·관리 코드 중 하나 이상이 틀림 | **둘 중 무엇이 틀렸는지는 알려 주지 않습니다.** 남의 주문번호를 찍어 보는 것을 막기 위해서입니다. 관리 코드를 잃었다면 학생회가 대신 취소 |
| 입금 확인 후에는 학생회에 문의해 취소해주세요. | 이미 입금 확인된 주문을 본인이 취소하려 함 | 학생회가 관리자 화면에서 처리 |
| 이미 처리된 신청입니다. 현재 상태: X. | 조회한 순간과 취소 누른 순간 사이에 관리자가 상태를 바꿈 | 현재 상태 확인 후 안내 |
| 확인 기간이 종료되었습니다. | 수령 확인 마감이 지남 | 마감을 늘리려면 관리자 설정에서 변경 |

### 그 밖

| 문구 | 실제 원인 | 할 답 |
|---|---|---|
| 응답이 오지 않아 중단했습니다. 네트워크를 확인하고 다시 눌러주세요. | 알림 켜기가 제한 시간 안에 끝나지 않음 | 네트워크 확인 후 다시 누르기. 지하철·엘리베이터에서 흔함 |
| 알림 설정에 실패했습니다. 잠시 후 다시 시도해주세요. | 브라우저 구독은 됐지만 서버 등록 실패 | 다시 시도. 반복되면 학생회 문의 |
| 알림이 차단되어 있습니다. 브라우저 설정에서... | 예전에 "차단"을 눌렀음 | **사이트에서는 되돌릴 수 없습니다.** 브라우저 설정 → 사이트 권한에서 알림을 허용으로 바꿔야 합니다 |
| 알림 기능이 아직 설정되지 않았습니다. | 서버 알림 설정 누락 | 개발자 문의 |
| 브라우저에는 등록됐지만 서버 등록이 끝나지 않았습니다. | 서버 등록만 실패 | 화면의 "알림 등록 다시 시도" 누르기 |

## B-2. 관리자가 보는 문구

### 공지·첨부

| 문구 | 실제 원인 | 조치 |
|---|---|---|
| 로그인이 풀렸습니다. 다시 로그인해주세요. | 세션 만료 | **입력한 내용은 그대로 남아 있습니다.** 다른 탭에서 로그인한 뒤 돌아와 저장 |
| 저장은 완료됐지만 목록 갱신에 실패했습니다. | 공지는 저장됨. 목록만 못 불러옴 | **새로고침만 하세요. 다시 등록하면 중복됩니다** |
| 응답을 받지 못했습니다. 저장됐는지 아래 목록을 확인한 뒤... | 요청은 갔는데 응답이 유실됨 | 목록 확인. 있으면 저장된 것 |
| 업로드가 진행되지 않습니다. 네트워크를 확인하고... | 구글이 세 번 연속 아무것도 받지 못함 | 네트워크 확인 후 다시 첨부 |
| 업로드 응답이 없습니다. 다시 시도해주세요. | 제한 시간 초과 | 다시 시도 |
| 시간이 초과됐습니다. 네트워크를 확인하고... | 한 파일에 5분을 넘김 | 파일을 줄이거나 네트워크 확인 |
| 작업이 취소됐습니다. | 업로드 중에 폼을 바꾸거나 초기화함 | 정상 동작 |
| 파일 내용이 확장자와 일치하지 않습니다. | 확장자만 바꾼 파일 | 원래 형식으로 저장해 다시 올리기 |
| 업로드가 완전히 끝나지 않았습니다. | 드라이브에 도착한 크기가 원본과 다름 | 다시 시도 |
| 구글 드라이브가 연결되어 있지 않아 4MB 이하만 올릴 수 있습니다. | 드라이브 연결 끊김 | 사이트 설정에서 드라이브 다시 연결 |
| 업로드 세션이 만료됐거나 올바르지 않습니다. | 업로드 표가 만료됨(오래 방치) | 파일을 다시 선택 |
| 파일 크기는 30MB 이하여야 합니다. | 한도 초과 | 압축하거나 나눠서 |
| 빈 파일은 첨부할 수 없습니다. | 0바이트 파일 | 파일 확인 |

### 캠페인 운영

| 문구 | 실제 원인 | 조치 |
|---|---|---|
| 이미 사용 중인 slug 입니다. | 주소가 다른 캠페인과 겹침 | 다른 주소 사용 |
| N건이 있어 삭제할 수 없습니다. 비공개로 전환하세요. | 신청이 들어온 캠페인은 지울 수 없음 | 설정에서 공개를 끄면 학생에게 안 보입니다. **의도된 보호 장치입니다** |
| 해석하지 못한 행이 N건 있어 적재하지 않았습니다. | CSV에 알아볼 수 없는 행이 있음 | **한 건도 들어가지 않았습니다.** CSV를 고쳐 다시 |
| N행 이름: 해석 불가 "..." | 항목 표기가 `사이즈 수량` 형식이 아님 | 해당 행 수정 |
| N행 이름: 상태 "X" 인식 불가 | 상태 칸 값이 이상함 | 대기 / 입금 / 수령 / 취소 중 하나로 |

### 로그인·시스템

| 문구 | 실제 원인 | 조치 |
|---|---|---|
| 아이디 또는 비밀번호가 올바르지 않습니다. | 자격 불일치 **또는 잠금 상태** | 비밀번호가 맞는데 안 되면 10분 기다리기 |
| Drive 연결과 부모 폴더 설정이 필요합니다. | 드라이브 미연결 | 사이트 설정에서 연결 |
| ANON_SALT 미설정 — Vercel 환경변수에 설정하세요 | 서버 설정 누락. **사이트 전체가 뜨지 않습니다** | 개발자가 환경변수 설정 |

## B-3. 오류가 아닌데 오류처럼 보이는 것

| 상황 | 실제 |
|---|---|
| 대시보드 숫자가 `-` 로 나옴 | 0건이 아니라 **집계를 못 불러온 것**. 새로고침 |
| 목록이 비어 있음 + 오류 문구 있음 | 데이터가 없는 게 아니라 **통신 실패**. 이 둘은 화면에서 구분됩니다 |
| 고친 내용이 안 보임 | 화면 저장 시간(최대 5분). 부록 A-5 참고. **다시 저장하지 마세요** |
| 첨부 저장 위치가 "사이트 저장소" | 드라이브 연결이 끊겨 대체 저장된 것. 파일은 정상이지만 연결을 복구하는 게 좋습니다 |
| 알림을 보냈는데 "받는 사람이 없습니다" | 정상 동작. 아직 아무도 알림을 켜지 않았을 뿐 |
